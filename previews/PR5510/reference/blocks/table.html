Table ​

The Table block displays tabular data with interactive features like row selection, column sorting, and scrolling.

julia
using GLMakie

fig = Figure()

# Sample data
data = (
    name = ["Alice", "Bob", "Charlie", "Diana", "Eve"],
    age = [28, 35, 42, 31, 25],
    city = ["New York", "Los Angeles", "Chicago", "Houston", "Phoenix"]
)

t = Table(fig[1, 1]; data = data)

# Listen to selection changes
on(t.selection) do sel
    if sel !== nothing
        println("Selected: ", sel)
    end
end

fig

Styling ​

You can customize the appearance of the table with various styling attributes:

julia
using GLMakie

fig = Figure()

data = (
    id = 1:10,
    name = ["Item $i" for i in 1:10],
    value = rand(10) .* 100
)

t = Table(fig[1, 1];
    data = data,
    header_color = RGBf(0.2, 0.4, 0.6),
    header_textcolor = :white,
    cell_color_even = RGBf(0.95, 0.95, 1.0),
    cell_color_odd = RGBf(0.9, 0.9, 0.95),
    cell_color_selected = RGBf(0.7, 0.85, 1.0),
    row_height = 30.0,
    header_height = 35.0
)

# Select row 3 by default
t.i_selected[] = 3

fig

Scrolling ​

When max_visible_rows is set, the table becomes scrollable:

julia
using GLMakie

fig = Figure()

# Large dataset
data = (
    row = 1:50,
    name = ["Entry $i" for i in 1:50],
    value = rand(50)
)

t = Table(fig[1, 1];
    data = data,
    max_visible_rows = 10
)

fig

Per-Cell Colors ​

You can provide a matrix for cell_color and/or cell_textcolor to color individual cells:

julia
using GLMakie

fig = Figure()

data = (
    name = ["Alice", "Bob", "Charlie", "Diana"],
    score = [95, 82, 78, 91],
    status = ["Pass", "Pass", "Fail", "Pass"]
)

# Create color matrix based on data
colors = [
    RGBf(0.9, 1.0, 0.9)  RGBf(0.9, 1.0, 0.9)  RGBf(0.9, 1.0, 0.9);
    RGBf(0.9, 1.0, 0.9)  RGBf(1.0, 1.0, 0.8)  RGBf(0.9, 1.0, 0.9);
    RGBf(0.9, 1.0, 0.9)  RGBf(1.0, 0.8, 0.8)  RGBf(1.0, 0.8, 0.8);
    RGBf(0.9, 1.0, 0.9)  RGBf(0.9, 1.0, 0.9)  RGBf(0.9, 1.0, 0.9)
]

t = Table(fig[1, 1];
    data = data,
    cell_color = colors
)

fig

Sorting ​

Click on column headers to sort by that column. Click again to toggle between ascending and descending order.

julia
using GLMakie

fig = Figure()

data = (
    name = ["Zebra", "Apple", "Mango", "Banana", "Cherry"],
    count = [5, 12, 8, 15, 3]
)

t = Table(fig[1, 1];
    data = data,
    sortable = true,
    show_sort_indicator = true
)

# Sort by the second column (count), descending
t.sort_column[] = 2
t.sort_direction[] = :descending

fig

Callbacks ​

You can register callbacks for various interactions:

julia
# Single click callback
t.on_row_click[] = (table, row_index, row_data) -> begin
    println("Clicked row $row_index: $row_data")
end

# Double click callback
t.on_row_doubleclick[] = (table, row_index, row_data) -> begin
    println("Double-clicked row $row_index")
end

# Sort change callback
t.on_sort_change[] = (table, column_index, direction) -> begin
    println("Sorted by column $column_index ($direction)")
end

Auto-Fit Columns ​

You can automatically resize columns to fit their content using auto_fit_columns!:

julia
using GLMakie

fig = Figure()
data = (
    name = ["Short", "A much longer name here", "Medium"],
    value = [1, 2, 3]
)

t = Table(fig[1, 1]; data = data)

# Render once, then auto-fit columns to content
display(fig)
auto_fit_columns!(t.plots[1])  # Access the TablePlot

fig

Similarly, auto_fit_rows! adjusts row heights to fit text content.

Attributes ​

alignmode ​

Defaults to Inside()

The alignment mode of the table in its parent GridLayout.

cell_color ​

Defaults to automatic

Per-cell background colors as a Matrix. If automatic, uses even/odd coloring.

cell_color_even ​

Defaults to RGBf(0.98, 0.98, 0.98)

Background color of even-numbered data rows (when cell_color is automatic).

cell_color_hover ​

Defaults to COLOR_ACCENT_DIMMED[]

Background color of the hovered row.

cell_color_odd ​

Defaults to RGBf(0.94, 0.94, 0.94)

Background color of odd-numbered data rows (when cell_color is automatic).

cell_color_selected ​

Defaults to COLOR_ACCENT[]

Background color of the selected row.

cell_fontsize ​

Defaults to 12.0

Font size of data cell text.

cell_padding ​

Defaults to (8, 8, 4, 4)

Padding inside cells as (left, right, bottom, top).

cell_selection ​

Defaults to nothing

The data of the currently selected cell. This is the output observable for cell-level selection.

cell_textcolor ​

Defaults to :black

Text color of data cells.

column_names ​

Defaults to automatic

Custom column names to display. If automatic, uses the data's keys.

column_widths ​

Defaults to :auto

Column widths. Can be :auto (equal widths), :fit (auto-fit to content), a number (all same width), or a vector of widths.

data ​

Defaults to (a = [1, 2, 3], b = ["x", "y", "z"])

The tabular data to display. Can be a NamedTuple or Dict{Symbol, Any} where each value is a column vector.

grid_color ​

Defaults to RGBf(0.8, 0.8, 0.8)

Color of grid lines.

grid_linewidth ​

Defaults to 1.0

Width of grid lines.

halign ​

Defaults to :center

The horizontal alignment of the table in its suggested bounding box.

header_color ​

Defaults to RGBf(0.2, 0.2, 0.2)

Background color of the header row.

header_fontsize ​

Defaults to 14.0

Font size of the header text.

header_height ​

Defaults to 30.0

Height of the header row in pixels.

header_textcolor ​

Defaults to :white

Text color of the header row.

height ​

Defaults to Auto()

The height setting of the table.

i_selected ​

Defaults to 0

Index of the currently selected row. 0 means no selection.

i_selected_cell ​

Defaults to (0, 0)

Selected cell as (row, col) tuple. (0, 0) means no cell selection.

max_visible_rows ​

Defaults to nothing

Maximum number of visible rows. If nothing, shows all rows.

on_cell_click ​

Defaults to nothing

Callback function (table, row, col, cell_data) -> nothing called on cell click.

on_cell_rightclick ​

Defaults to nothing

Callback function (table, row, col, cell_data) -> nothing called on cell right-click.

on_row_click ​

Defaults to nothing

Callback function (table, row_index, row_data) -> nothing called on row click.

on_row_doubleclick ​

Defaults to nothing

Callback function (table, row_index, row_data) -> nothing called on row double-click.

on_sort_change ​

Defaults to nothing

Callback function (table, column_index, direction) -> nothing called when sort changes.

row_height ​

Defaults to 25.0

Height of each data row in pixels.

row_heights ​

Defaults to automatic

Row heights. Can be automatic (uniform using row_height), a number, or a vector of heights per row.

scroll_offset ​

Defaults to 0

Current scroll offset (row index to start displaying from).

scroll_speed ​

Defaults to 3.0

Scroll speed multiplier for mouse wheel scrolling.

selection ​

Defaults to nothing

The data of the currently selected row as a NamedTuple. This is the output observable to listen to.

show_grid ​

Defaults to true

Whether to show grid lines.

show_horizontal_lines ​

Defaults to true

Whether to show horizontal grid lines.

show_sort_indicator ​

Defaults to true

Whether to show sort direction indicator (↑/↓) in the header.

show_vertical_lines ​

Defaults to true

Whether to show vertical grid lines.

sort_column ​

Defaults to 0

Index of the column to sort by. 0 means no sorting.

sort_direction ​

Defaults to :ascending

Sort direction, either :ascending or :descending.

sortable ​

Defaults to true

Whether clicking column headers enables sorting.

tellheight ​

Defaults to true

Controls if the parent layout can adjust to this element's height.

tellwidth ​

Defaults to true

Controls if the parent layout can adjust to this element's width.

valign ​

Defaults to :center

The vertical alignment of the table in its suggested bounding box.

width ​

Defaults to nothing

The width setting of the table.
